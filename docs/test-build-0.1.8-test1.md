# 0.1.8 — 外部 FLM 实验闸门与校验说明修正

开发验证使用 0.1.8-test1 / versionCode 22；正式构建为 0.1.8 / versionCode 23，功能一致，保留与 0.1.6/0.1.7 相同的本机 debug 签名。

## 本次变更

- 外部 FLM 每次应用进程启动默认停用，开启状态不持久化。关闭时可以导入/查看文件，保留旧绑定，但目标目录和执行器只提供内置支持。
- 单独的实验开启确认说明具体料号尚无实板验证、布局匹配不证明兼容，以及 MCU 代码不受主机地址检查的沙箱约束。开启会恢复保存的绑定；新绑定再次确认，并冻结目标设备信息，在提交时核对。
- 校验与执行入口均检查当前权限和授权代次。关闭后再开启不会让之前创建的外部执行器复活。烧录、识别、固件/算法导入及批次期间禁止切换。
- 外部绑定显示“实验 · 未验证”；内置 F1 不修改 Option Bytes/RDP 的保证不扩展至外部机器码，保留区说明同步明确此边界。
- 移除未实现的 CRC32 UI 选项。旧设置值 1 迁移为完整回读值 0，原“不校验”值 2 保持不变。两选项 UI 不重新解释旧索引。
- “整片擦除”改为“全部非保留区”，附逐扇区擦除且跳过保留区的说明。擦除计划逻辑未变。
- [Unicorn 脚本与固定依赖](thumb-runtime-validation.md)入库，旧验证记录补充可复现入口，明确模拟检查与实板证据区别。

## 验证

- `:core:test :app:testDebugUnitTest :app:assembleDebug :app:lintDebug --offline` 通过；审查发现固件导入锁定遗漏后补齐，重新执行 app 测试、构建与 lint 通过。
- 185 项测试（core 164 + app 21），0 failures / errors。新增 4 项实验权限/陈旧执行器检查与 3 项校验偏好迁移/索引检查。
- 独立代码审查通过，固件导入期间 UI 与 VM 锁定遗漏已修正。
- `scripts/verify-thumb-runtime.py` 普通及 `python -O` 模式两项 PASS；NDK LLVM 重新汇编与 48 字节 F1 内嵌代码、BKPT 0x26 一致。
- Pixel 9 Pro / API 35 后台模拟器：默认关闭、单独确认后开启、结束进程并重新启动后恢复关闭；配置页仅“回读全部/不校验”，擦除选项显示“全部非保留区”。未连接硬件，未执行实际擦写。

本次未验证外部 FLM 的真实芯片兼容性，未增加已验证算法白名单或具体料号实板记录。内置 F1 的既有实板记录仍限原验证组合。

正式构建再次通过 core/app 单元测试、assembleDebug 和 lintDebug，APK 签名与已发布 0.1.6 相同；版本号增加至 23，可以覆盖测试包升级。
