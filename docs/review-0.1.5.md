# Corn Flashing 0.1.5 — 真实擦写

## 已打开
- ST-LINK/V2 → STM32F1：页擦除（FLASH_CR PER）、半字编程（PG）、回读校验、可选复位（RESETSYS / NRST / 解停核）。
- 配置页擦除偏好：0=规划页，1=整片容量内逐页擦（跳过保留区）；校验：0/1=回读，2=跳过。
- 「完成后复位运行」真实路径生效；「自动换板」成功后轮询新 UID 再开单路。
- 批次：关闭模拟时可单工位真实连续（先识别芯片；每块板探测后烧录）。多工位仍未开放。
- 不修改 Option Bytes / 不解除 RDP。

## 仍未开放
- 闪灯定位（无可靠 V2 LED 协议）。
- 多工位并行、可编辑保留区、配置备份。
- 校验「CRC32」UI 目前仍走完整回读（与「回读全部」相同）。

## 风险提示
真实擦写会改 Flash。请用已知固件、确认接线与目标供电；若芯片有读保护，本应用会报解锁失败且不会尝试解除。
